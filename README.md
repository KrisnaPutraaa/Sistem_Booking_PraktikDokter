# Praktik THT-KL: website antrean pasien

Website antrean untuk praktik dr. Luh Putu Dhena Purwaningsih, Sp.THT-KL.
Panduan lengkap: [docs/Panduan_Pengerjaan_Website_Antrean_THT.pdf](docs/Panduan_Pengerjaan_Website_Antrean_THT.pdf).
Screenshot desain: [docs/desain/](docs/desain/).

## Menjalankan

Butuh Node.js 22.12+ (disarankan 24 LTS).

```bash
npm install
cp .env.example .env.local   # lalu isi nilainya
npm run dev
```

Perintah lain: `npm run build`, `npm run lint`, `npm run typecheck`, `npm test`.
